# 2026-10-22 设计｜右栏重排：结果窗上移 + 配置组折叠 v1.0

> 源：用户 2026-10-22 指令「将结果窗口挪动 tab 开关下方，原位置组件组成配置组折叠隐藏在结果窗口下方」。
> 范围：`src/App.tsx`（右栏容器）、`src/components/processing/ProcessingPanel.tsx`（结构重排 + 配置组折叠）、`src/components/results/ResultView.tsx`（被面板内嵌）。

## 1. 目标结构（右栏自上而下）

```text
右栏（h-[560px] / lg:h-[640px]，单卡片）
├─ 处理（标题 + 「N 章」/「EPUB」徽标）
├─ [模式 tab：当前章节总结 | 当前章节思维导图 | 整书思维导图]
├─ 状态行（运行中进度条 / 暂停按钮 / 空闲提示 / 错误文案）
├─ 结果窗口（flex-1，内部滚动）   ← ResultView 从 App 移入此处
└─ 配置组（默认折叠，置底）
   ├─ 折叠头：〔配置（服务 / 高级选项）⌄〕
   └─ 展开内容：服务下拉 / 智能章节检测 / 跳过无关章节 / 子章节深度
```

## 2. 变更点

| # | 变更 | 说明 |
| --- | --- | --- |
| 1 | `ResultView` 由 `App` 移入 `ProcessingPanel` | 结果窗紧贴 tab 下方；`App` 右栏只保留 `<ProcessingPanel />`，移除独立结果容器与 `ResultView` 导入 |
| 2 | 原「服务 / 高级选项」区降级为**配置组** | 默认折叠（`configOpen=false`），置于结果窗之下；折叠头一行、可点开合；展开后保留原有全部控件 |
| 3 | 进度/暂停/错误行上移 | 从底部（`mt-auto`）移到 tab 正下方，保证运行中状态始终可见；结果窗与配置组各占剩余空间 |
| 4 | 面板滚动模型调整 | 外层 `overflow-hidden`，仅结果窗内部 `overflow-y-auto`；配置组展开不挤压结果窗（外层不滚动） |

## 3. 交互约定

- 空闲时结果窗显示占位「处理完成后将在此展示总结与思维导图。」，配置组折叠 → 右栏首屏即「tab + 空结果 + 折叠配置」。
- 点 tab 立即处理；结果出现在 tab 下方（无需滚动页面）。
- 「配置」折叠头带当前服务名提示，展开后可切换服务 / 调整高级选项。

## 4. 验收

- 右栏 DOM 顺序：tablist → 状态行 → `#app-result` → 配置组折叠头；配置默认折叠（高级选项不可见），点开后可见「服务 / 智能章节检测 / 跳过无关章节 / 子章节深度」。
- 跑「当前章节总结」→ 导读出现在 tab 下方的结果窗内（x 在右栏范围内，y > tablist 底边）。
- 折叠组展开/收起不影响结果窗内容与已生成结果。
- typecheck / build 绿；写后必查；`pnpm` 脚本仅 typecheck/build。
