# 2026-10-22 设计｜恢复章节列折叠 + 移除封面框 v1.0

> 源：用户 2026-10-22 反馈「章节选择窗口的折叠按钮消失了」「去除封面显示框」。
> 背景：阶段 14「移除总结/大纲开关及相关组件」时把章节列的折叠能力（`outlineVisible` + 折叠按钮 + 折叠侧栏导轨）一并移除，导致用户无法再折叠章节列。

## 1. 变更

| # | 变更 | 说明 |
| --- | --- | --- |
| 1 | 恢复章节列折叠 | `reader-store` 重新加入 `outlineVisible` / `setOutlineVisible`（随 `ai-read:reader` 持久化）；`ChapterList` 恢复「«」折叠按钮；`App` 恢复两态 grid：展开 `[minmax(0,1fr)_minmax(0,1.4fr)_360px]`、折叠 `[40px_minmax(0,1fr)_360px]` 并显示竖排「章节」导轨按钮用于再展开 |
| 2 | 移除封面显示框 | `BookUploader` 不再渲染 `book.cover` 图片框（解析与存储字段保留，仅不展示） |

## 2. 验收

- 章节列表工具条出现「«」折叠按钮 → 点击后章节列收为 40px 导轨 → 点击导轨恢复三栏 ✓
- 上传区不再出现封面图片框 ✓
- typecheck / build 绿；写后必查。
