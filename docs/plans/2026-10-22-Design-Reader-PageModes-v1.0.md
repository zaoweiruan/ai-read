# 2026-10-22 设计｜阅读区：图标缩放 · AI 面板折叠 · 双页并列 · 换页方式 v1.0

> 源：用户 2026-10-22 指令四项：①「注」图标太大 ② AI 处理窗口加折叠按钮 ③ 内容窗口加「同时并列显示两页」按钮 ④ 内容窗口加换页方式配置（连续、切换）。
> 范围：`src/stores/reader-store.ts`、`src/types/index.ts`、`src/components/content/BookContent.tsx`、`src/components/processing/ProcessingPanel.tsx`、`src/App.tsx`。

## 1. 小图标缩放（"注" 图标）

EPUB 的 CSS 未被保留，图片按**原始像素**渲染，导致书中的小图标（注 记号）显得过大。
修复：新增 `ReaderImage` 组件 —— 图片载入后若 `naturalWidth ≤ 200`（图标类）则限宽 **2em**（随正文字号缩放）；插图类保持原尺寸，仍受 `max-h-[70vh] max-w-full` 约束。

## 2. AI 处理窗口折叠

- `reader-store` 增加 `processingVisible`（持久化，默认 true）。
- `ProcessingPanel` 标题行右侧新增折叠按钮（收起图标）→ 面板隐藏。
- `App` 第三列在折叠时收为 **40px「处理」导轨**（竖排文字按钮），点击恢复 360px 面板（与章节列折叠同一交互范式）。

## 3. 双页并列（连续内容分两栏）

- `reader-store` 增加 `twoPage`（持久化，默认 false）；工具条新增「双页」按钮。
- **行为**：双页开启后，**同一页（PDF）/ 同一屏（EPUB、Markdown）的内容连续分为左右两栏**（CSS `columns-2`），阅读顺序为「左栏 → 右栏 → 下一屏」，**不再左右各放一页不同内容**。
- **切换 + 双页**：改为**书页式横向分页** —— 内容以视口高度为栏高流入两栏并向右侧溢出，每屏推进一个**跨页**（左页 → 右页 → 下一跨页），`transform: translateX` 位移；跨页数 = `ceil(内容总宽 / 跨页宽)`，全部内容均可看完（此前版本是「两栏 + 纵向切片」，会把两栏同时横切，顺序错乱且看不到剩余内容）。
- **边缘行对齐**：栏高不再是「视口高」而是 **行高整数倍**（`usableH = floor((视口高 - 内边距) / 行高) × 行高`），行高取当前字号 × 行距倍数；因此窗口上下的行**整行起排、不会被切一半**（实测 342px = 10 × 34.2px）。单页纵向翻页同样使用该对齐高度。
- 翻页：仍按原页序推进 —— PDF 每次一页（指示「第 N / M 页」），EPUB / Markdown 按跨页推进（指示「第 N / M 跨页」，单页时为「屏」）。
- 保留 2026-10-22 早期的「连续页对（1-2、3-4）」方案记录：它适用于「左右各放一页原始页」的需求；本次按用户最新要求改为「连续内容分两栏」。

## 4. 换页方式（连续 / 切换）

- `reader-store` 增加 `pageMode: 'continuous' | 'paged'`（持久化，默认 continuous）；工具条提供 [连续] / [切换] 两个切换按钮。
- **连续**：现有行为（自由滚动，滚到底自动进下一章，滚到顶回上一章）。
- **切换**：整屏翻页 —— 内容按视口高度分屏（`translateY` 位移，滚动容器 `overflow-hidden`），滚轮/上一页/下一页按屏翻；末屏再向下 → 下一章；首屏再向上 → 上一章并**落在其末屏**（连续向上阅读）。屏幕数由内容高度 ÷ 视口高度实时计算（ResizeObserver）。正文下方常驻提示「**第 N / M 屏 · 向下滚动或点「下一页」继续查看本章后续内容**」，避免误以为内容被截断。

## 7. 工具条合并为单行（2026-10-22 追加）

阅读区原有两行工具条（排版行 + 导航行）合并为**一个** `flex flex-wrap` 行：排版（A-/A+/行距/字距/字体/主题）、重置、全屏、章节导航（上一章/下一章）、页码导航（上一页/页码/下一页）、双页、换页方式（连续/切换）、连续滚动全部同处一行。

- **宽度自适应**：容器 `flex-wrap` —— 宽度足够时**一行排开**（实测 1200px → 1 行），宽度不足时**自动折行**（900px → 2 行；600px → 2 行；449px → 3 行）。
- **紧凑化**：新增 `.reader-toolbar > button` 规则统一按钮高度 1.75rem、左右内边距 0.5rem、字号 0.75rem，控件总宽由约 1100px 降至 **793px**（一行所需宽度 ≈ 810px）。
- 想让阅读区更宽以排成一行：折叠右侧「处理」面板（右栏变 40px 导轨）或进入全屏。

- 书中「注」图标显示为约 2em（≈36px）而非原始 80px；插图不受影响。
- AI 面板可折叠为 40px 导轨并可再展开。
- 「双页」：PDF 两页并列、EPUB 正文双栏。
- 「切换」模式：滚轮/按钮逐屏翻页，末屏进下一章、首屏回上一章（定位末屏）；「连续」模式行为不变。
