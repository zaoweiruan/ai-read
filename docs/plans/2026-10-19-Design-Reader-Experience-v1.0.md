# 2026-10-19 设计 阅读体验优化 v1.0

## 参考

仿照 3min.top 阅读器（经 127.0.0.1:10808 代理抓取分析其前端产物）：

- 阅读排版核心变量：`--reader-font-size: 19px`、`--reader-line-height: 1.5`，正文列宽约 `65ch`。
- 阅读器设置：字体（系统/衬线/无衬线/等宽/中文优化）、字号、行高、主题色（清白/羊皮卷/晨林/薰衣草/琥珀/鼠尾草/墨夜 等 8 套）、恢复默认。
- 信息面板（右侧）：大纲 / 总结 / 翻译 / 思维导图 / 对话 / 划线，各面板可展开收起、跳转。
- 书籍总结分区：摘要 / 目标读者 / 作者背景 / 章节摘要 / 章节目录。

本项目只落地与现有功能匹配的部分（无翻译/对话/划线后端能力）。

## 功能设计

### 1. 章节窗口（大纲）可折叠、隐藏

- 「章节选择」列可折叠为 40px 细栏（竖排「章节」按钮），点击恢复；状态持久化。
- 书籍内容区工具栏提供「大纲」开关，与细栏按钮双向联动。

### 2. 书籍内容友好排版

- EPUB 文本提取改为**按块（段落）提取**（p/div/li/h1-h6/blockquote/pre/figcaption 为块边界），
  块间以空行分隔；PDF 维持按页文本。
- 正文按段落渲染 `<p>`：段间距 0.9em、首行缩进 2em（中文排版习惯）。
- 排版控件（书籍内容区工具栏，全部持久化）：
  | 控件 | 选项 | 默认 |
  | --- | --- | --- |
  | 字号 | 15–22px（A-/A+ 步进 1px） | 18px |
  | 行距 | 1.6 / 1.9 / 2.2（循环切换） | 1.9 |
  | 字距 | 0 / 0.02em / 0.05em（循环切换） | 0.02em |
  | 字体 | 黑体(无衬线) / 宋体(衬线) / 楷体（循环切换） | 黑体 |
  | 主题 | 日光(白) / 米黄(纸) / 护眼(绿) / 墨夜(深)（循环切换） | 日光 |
- 「重置」恢复默认排版。主题仅作用于阅读区背景/文字色。

### 3. 大纲 / 总结开关

- 「总结」开关：在阅读区顶部显示/隐藏「本章总结」卡片（数据来自文字总结模式的
  `summary.chapterSummaries[当前章节]`）；尚无总结时卡片内提示先运行文字总结。
- 「大纲」开关：同第 1 节，控制章节列显隐。
