# 2026-10-19 设计 布局-工作台 v1.0

## 背景

原页面为单列纵向堆叠（上传 → 章节选择 → 处理 → 结果），上下滚动较多；查看章节正文没有入口。
需求：将「章节选择」「书籍内容（新增）」「处理模式（纵向一组）」三个区域水平排列为工作台，且区域间联动；结果区保持在下方。

## 布局

```text
┌──────────────────────────────────────────────────────────┐
│ 上传区（全宽，保持不变）                                    │
├──────────────┬───────────────────────┬───────────────────┤
│ 章节选择      │ 书籍内容              │ 处理（模式）        │
│ (1fr)        │ (1.4fr)               │ (260px)           │
│ 复选框列表    │ 当前章节正文           │ 模式列表（纵向）    │
│ + 分组        │ （点击章节按需加载）    │ 服务 / 高级选项    │
│              │                       │ [开始处理] 进度    │
├──────────────┴───────────────────────┴───────────────────┤
│ 结果区（全宽：文字总结 / 思维导图，保持不变）                 │
└──────────────────────────────────────────────────────────┘
```

- 工作台行高固定 480px（lg 断点以上），三区域各自内部滚动、等高对齐；
  小于 lg 时退化为纵向堆叠（每区 420px 高）。
- 网格：`lg:grid-cols-[minmax(0,1fr)_minmax(0,1.4fr)_260px]`。

## 联动

- 「章节选择」中点击章节**标题** → 写 `book-store.activeChapterId` →
  「书籍内容」按需加载该章正文并滚动到顶部，当前行高亮。
- 复选框（多选）仅决定处理范围，与「查看内容」互不干扰、可并存。
- 上传新书时 `activeChapterId` 自动指向第一章；`reset` 时清空。
- 「开始处理」位于「处理」区底部；完成后结果写入 store，下方结果区按现有
  文字总结 / 思维导图 tab 展示（含 scaleFit 的 mind-elixir 渲染）。
